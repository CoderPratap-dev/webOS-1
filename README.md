# NOVA OS

A simple web-based operating system built with HTML, CSS and JavaScript.

NOVA OS is my WebOS 1 project for Stardance. The goal was to create a small desktop environment that runs directly in a web browser.

<img width="1858" height="907" alt="image" src="https://github.com/user-attachments/assets/b5b23703-d41a-46a6-bd00-5d53be4da09d" />


## Features

- Simple desktop interface
- Top system bar with live clock
- Taskbar
- Start menu
- Files application
- Notes application
- Settings application
- Multiple draggable windows
- Notes auto-save using browser localStorage
- No login or password required

## Tech Used

- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

That's it.
